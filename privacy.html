Privacy Policy

Last updated: 22 November 2026

About this application

Personal Oura Health Analytics is a private, non-commercial application being developed for personal use.

Data collection

The application is intended to retrieve health measurements from the Oura API only with the account holder's authorisation.

Data usage

Authorised data will be used for personal health analysis and software development. API-derived data will not be supplied to third-party AI systems in violation of Oura's applicable terms.

Data storage

During development, health data will be processed locally. Authentication credentials will not be published in source-code repositories.

Data sharing

The application is not intended to share personal health data with other users or commercial third parties.

Data deletion

Locally stored application data can be deleted by the account holder. Access can be revoked through Oura's available account controls.
